# BMS Web Monitor — мульти-паковий веб-монітор Vision (tools/bms_web.py)

**Версія:** v2.0 (27.10.2026) · **Стан:** читання (read-only), мульти-пакове сканування, автопошук 1..16, перемикач режимів Active/Passive на льоту

Локальний веб-додаток для macOS (або будь-якої системи з Python) — повноцінний аналог
Windows-програми **BMS_TOOLS_2.2.01** для банку акумуляторів Vision V-LFP48100 (до 16 АКБ).

---

## Що робить (v2.0 Multi-Pack)

1. **Автоматичне сканування всіх 16 адрес (0x01..0x10):**
   * При старті або натисканні кнопки **«🔄 Пересканувати всі 16»** скрипт робить швидкий прогін по адресах 0x01..0x10 (~1.8 с).
   * Виявляє всі реально підключені АКБ та переходить на швидке опитування **лише наявних батарей** (цикл 0.35 с).
   * **Plug & Play / Hot-plug:** у кожному циклі у фоновому режимі перевіряється 1 неактивна адреса. Якщо додати або увімкнути новий акумулятор — він автоматично з'являється у системі без перезапуску.
   * **Hot-unplug:** якщо акумулятор вимкнено або від'єднано (3 таймаути поспіль) — він автоматично позначається як Офлайн і прибирається зі швидкого пулу.

2. **Перемикання режимів на льоту (кнопка в інтерфейсі):**
   * **⚡ Активний режим (Master):** скрипт самостійно опитує знайдені АКБ запитами `FC03 qty=39` (усі 39 регістрів). Використовується, коли шина вільна (коробка або інвертор вимкнені/відключені).
   * **👂 Пасивний режим (Sniffer):** нуль передач у шину (повна відсутність колізій). Скрипт слухає трафік між COM-Box/інвертором та батареями, розпізнає пакети для будь-яких адрес (0x01..0x10) і оновлює дані в реальному часі.
   * Режим можна перемикати прямо у веб-інтерфейсі однією кнопкою!

3. **Вкладковий інтерфейс (Tabs):**
   * **📊 Загальний огляд банку (Summary):**
     * Середня напруга банку (В).
     * Сумарний струм (А) та загальна потужність (кВт) усього стеку АКБ.
     * Середній SOC (%) та сумарна залишкова ємність (А·ч).
     * Глобальний розбаланс усього банку (**Bank Δ** у мВ).
     * Глобальні екстремуми: найнижча комірка (напруга, номер АКБ та комірки) та найвища комірка.
     * Статус активного балансування по банку та лічильник тривог.
     * **Зведена таблиця** всіх знайдених АКБ зі швидким переходом до будь-якої батареї.
   * **🔋 Окремі вкладки для кожного знайденого АКБ (`АКБ 0x01`, `АКБ 0x02`...):**
     * 15 комірок (мВ) з кольоровим виділенням Min (червоний) / Max (зелений) та золотим бейджем **`[BAL]`** при активному балансуванні комірки.
     * Усі температури: PCB, середня, максимальна, Temp01..Temp04.
     * Статусні прапорці: Status (0025), Warning (0026), Protection (0027), Error (0028).
     * Регістр балансування 0038 (по-коміркова індикація).
     * Модель, прошивка BMS, серійний номер, SOH, лічильник циклів, Full Capacity.

4. **CSV-логування:**
   * Запис телеметрії всіх знайдених акумуляторів у файл `bms_monitor_<дата_час>.csv`.

## Запуск

```bash
# 1. Жива шина (автопошук всіх АКБ 0x01..0x10):
python3 tools/bms_web.py --port /dev/cu.usbserial-A5069RR4

# 2. Пасивний режим зі старту (паралельно з живим інвертором/COM-Box):
python3 tools/bms_web.py --port /dev/cu.usbserial-A5069RR4 --passive

# 3. Демо-режим без заліза (симуляція кількох АКБ з різними комірками та балансуванням):
python3 tools/bms_web.py --mock

# 4. Вбудована самоперевірка (CRC, парсинг, мульти-пакова агрегація):
python3 tools/bms_web.py --selftest

# 5. Список серійних портів:
python3 tools/bms_web.py --list
```

Веб-інтерфейс доступний за адресою: **`http://127.0.0.1:8080`**

---

## Параметри командного рядка

| Параметр | Дефолт | Що робить |
|---|---|---|
| `--port` | `/dev/cu.usbserial-A5069RR4` | серійний порт RS485-тапа |
| `--baud` | `9600` | швидкість (Vision = 9600 8N1) |
| `--addr` | `0x01` | стартова вкладка АКБ для фокусу |
| `--http` | `8080` | порт веб-сервера (127.0.0.1) |
| `--mock` | — | режим симуляції (без заліза, 2 тестових АКБ) |
| `--passive` | — | запустити одразу в пасивному режимі (sniffer) |
| `--selftest` | — | автотест CRC, парсера та розрахунку банку |
| `--list` | — | вивести доступні com-порти |

## Правила безпеки

1. **Тільки читання (Read-Only):** скрипт ніколи не відправляє команди запису (FC06/FC10), тому не може пошкодити налаштування або прошивку BMS.
2. **Пасивний режим при працюючій коробці / інверторі:** щоб не створювати колізій на шині RS485 при одночасній роботі COM-Box чи інвертора, перемикайте режим на **Пасивний** (`--passive` або кнопка в інтерфейсі).

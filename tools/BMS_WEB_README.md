# BMS Web Monitor & Diagnostics — станція моніторингу Vision (tools/bms_web.py)

**Версія:** v2.2 (28.10.2026) · **Стан:** читання (read-only), мульти-пак, автопошук 1..16, графіки, калькулятор автономності, діагностика комірок, калькулятор уставок інвертора, інтерактивні алярми, офлайн-аналізатор логів та PDF-паспорт

Локальний веб-додаток для macOS (або будь-якої системи з Python / Windows) — потужна діагностична веб-станція для банку акумуляторів Vision V-LFP48100 (до 16 АКБ).

---

## Що робить (v2.2 Multi-Pack & Full Diagnostics)

1. **Автоматичне сканування всіх 16 адрес (0x01..0x10):**
   * При старті або натисканні кнопки **«🔄 Пересканувати всі 16»** робить швидкий прогін по адресах 0x01..0x10 (~1.8 с).
   * Виявляє всі реально підключені АКБ та переходить на швидке опитування **лише наявних батарей** (цикл 0.35 с).
   * **Plug & Play / Hot-plug:** у фоновому режимі перевіряються порожні адреси. Якщо увімкнути новий акумулятор — він автоматично з'являється у системі.
   * **Hot-unplug:** при відключенні АКБ (3 таймаути поспіль) він позначається як Офлайн і виключається зі швидкого пулу.

2. **Калькулятор автономності (Time to Full / Time to Empty) та реальний OCV-SOC:**
   * Точний розрахунок накопиченої енергії банку в **кВт·год** (kWh).
   * **Прогноз заряду:** розрахунок точного часу до 100% при поточному струмі (наприклад: *«до 100%: ~1 год 20 хв при 15 А»*).
   * **Прогноз розряду:** розрахунок автономності під навантаженням (наприклад: *«автономність: ~6 год 15 хв при 850 Вт»*).
   * **3-режимний адаптивний SOC:** фізичний розрахунок відсотка заряду за адаптивними кривими гістерезису (заряд під струмом, розряд під навантаженням, стан спокою) поруч із заводським кулонометром BMS (регістр 0024), що захищає від помилок лічильника BMS і показує узгоджені 65–66% під струмом заряду.

3. **⚙️ Розумний калькулятор налаштувань інвертора (Inverter Settings):**
   * Кнопка **«⚙️ Налаштування інвертора»** у шапці автоматично розраховує безпечні та оптимальні параметри для Deye / Victron / Luxpower під фактичну кількість підключених акумуляторів (N × 100 А·год):
     * **Bulk / Absorption:** 52.50 В (Safe 3.50 В/ком) / 53.25 В (Max 3.55 В/ком)
     * **Float:** 50.55 В (3.37 В/ком)
     * **Low Battery Cut-off:** 44.25 В (2.95 В/ком)
     * **Restart Voltage:** 49.50 В (3.30 В/ком)
     * **Струми:** Оптимальний заряд (0.3C = N × 30 А), Максимальний заряд (0.5C = N × 50 А), Максимальний розряд (1.0C = N × 100 А).
   * Кнопка **«📋 Скопіювати для Deye / Victron»** в один клік копіює готовий текстовий конфіг для інженера.

4. **🚨 Інтерактивний довідник алярмів та статусів (Alarm & Protection Helper):**
   * Усі світлодіодні бейджі тривог, попереджень та статусів (Status, Warning, Protection, Error) є інтерактивними.
   * Клік по будь-якому біту відкриває інженерну картку з деталями:
     * Категорія регістра та точний шістнадцятковий код.
     * Рівень критичності (Штатний режим / Попередження / Аварія).
     * Фізичний опис першопричини спрацювання.
     * Конкретна інструкція інженеру щодо необхідних дій на об'єкті.

5. **📂 Офлайн-аналізатор записаних CSV-логів (Offline Log Viewer):**
   * Окрема вкладка в інтерфейсі з підтримкою **Drag & Drop** файлів логів `bms_monitor_*.csv`.
   * Працює на 100% локально в браузері без передачі файлів на зовнішні сервери.
   * Миттєво будує часовий графік напруги та струму за всю тривалість сеансу.
   * Формує таблицю по кожній з 15 комірок усіх АКБ: розмах напруг ($\Delta U$), розрахований внутрішній опір ($R_{int}$), кількість включень балансира та оцінка загального стану комірки («Відмінно», «Справна», «Увага»).

6. **🔬 Глибока діагностика комірок (Weak Cell & Health):**
   * **Weak Cell Tracker:** автоматично визначає, яка саме комірка у банку систематично відстає під навантаженням (наприклад: *«АКБ 0x01, ком. #8 відстає у 88% вимірювань»*).
   * **Динамічний внутрішній опір ($R_{int}$ у мОм):** аналізує реакцію напруги комірок $\Delta U$ на стрибки струму $\Delta I$ ($R = \Delta U / \Delta I$). Дозволяє виявити погано затягнуті болти на шинах або зношені комірки!
   * **Балансувальний таймер:** фіксує точний час роботи активного балансира для кожної комірки.

7. **📈 Живі графіки в реальному часі (HTML5 Canvas, без зовнішніх бібліотек):**
   * **Rolling Time Chart:** крива напруги (В), струму (А), потужності (кВт) та загальної дельти банку за останні 5–10 хвилин.
   * **Cell Bar Chart:** стовпчикова гістограма 15 комірок обраного АКБ з колірним підсвічуванням Min/Max, сяючим золотистим бейджем `[BAL]` для активного балансування та значенням $R_{int}$ під кожною коміркою.

8. **📄 Діагностичний паспорт-звіт (PDF / Друк):**
   * Кнопка **«📄 Діагностичний звіт»** формує акуратний готовий паспортний звіт банку на поточний момент, оптимізований під розмір рівно **1 аркуш A4**:
     * Загальний енергетичний статус банку.
     * Паспорт кожного АКБ (Model, SOH, FW, серійний номер, цикли, номінал).
     * Повна компактна матриця напруг усіх 15 комірок кожного АКБ, розрахунковий опір та дельти.
     * Журнал тривог та висновок інженерної діагностики з рекомендаціями.
     * Готовий до друку або збереження у PDF (`window.print()`).

9. **Кнопка перемикання режимів Active/Passive прямо в браузері:**
   * **⚡ Активний режим (Master):** опит шини запитами `FC03 qty=39`.
   * **👂 Пасивний режим (Sniffer):** 0 передач у шину (без колізій із COM-Box чи інвертором).

10. **4-рівнева система вкладок інтерфейсу:**
   * **📊 Загальний огляд (Summary):** сумарна напруга банку, струм, потужність, енергія, реальний та BMS SOC, автономність, індикатор найслабшої комірки та зведена картка всіх блоків.
   * **📈 Графіки та Діагностика (Charts & Deep Diagnostics):** Canvas-графіки часового тренду (розділені окремі графіки: напруга/струм банку та динаміка розбалансу комірок Δ мВ із порогом 50 мВ), гістограма 15 комірок із бейджем `[BAL]` та таблиця динамічного опору $R_{int}$.
   * **🔋 АКБ 0x01 ... 0x10 (Детальні вкладки блоків):** повна телеметрія кожного блоку, матриця комірок, 3 температури, розшифровка статусів/захистів та паспортні дані.
   * **📂 Аналіз логу (Offline CSV Log Viewer):** інтерактивний аналізатор збережених файлів телеметрії.

## Запуск

### Вимоги

* Python 3.8+.
* **pySerial** для роботи з реальним COM/USB-RS485 портом:

```bash
python3 -m pip install pyserial
```

`--mock` і `--selftest` працюють без pySerial.

### Автоматичне визначення порту (Windows / macOS / Linux)
Скрипт самостійно знайде підключений USB-RS485 адаптер (FTDI FT232, WCH CH340, CP2102, Prolific тощо).

```bash
# Універсальний запуск (macOS, Linux, Windows):
# Скрипт автоматично знайде потрібний COM/USB порт та запуститься у безпечному ПАСИВНОМУ режимі:
python3 tools/bms_web.py          # на macOS / Linux (за замовчуванням: Пасивний Sniffer)
python tools/bms_web.py           # на Windows

# Якщо потрібно запустити примусово в АКТИВНОМУ режимі Master (опитування батареї без COMBOX):
python3 tools/bms_web.py --active

# Якщо порт потрібно вказати примусово вручну:
python tools/bms_web.py --port COM3               # Windows
python3 tools/bms_web.py --port /dev/cu.usbserial-A5069RR4  # macOS

# Демо-режим без заліза (симуляція кількох АКБ, графіків та діагностики):
python3 tools/bms_web.py --mock   # macOS/Linux
python tools/bms_web.py --mock    # Windows

# Вбудована самоперевірка (CRC, парсер, калькулятор, автопошук):
python3 tools/bms_web.py --selftest

# Подивитися список усіх підключених портів у системі:
python3 tools/bms_web.py --list
```

Веб-інтерфейс доступний за адресою: **`http://127.0.0.1:8080`**

## Правила безпеки

1. **Тільки читання (Read-Only):** скрипт ніколи не відправляє команди запису (FC06/FC10), тому не може пошкодити налаштування або прошивку BMS.
2. **Пасивний режим при працюючій коробці / інверторі:** перемикайте на **Пасивний** (`--passive` або кнопка в інтерфейсі), щоб уникнути колізій на шині RS485.
